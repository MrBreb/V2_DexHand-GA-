# DexHand v2 - Early Access Repository

## Overview

Welcome to the DexHand v2 early access repository. This repository provides NVIDIA with an early look at the schematics and design files for DexHand v2. We appreciate your feedback and collaboration.

## License

The files in this repository are provided under the CERN OHL-S License. Please review the license terms before using the materials.

## Purpose of Early Access

This repository is shared with NVIDIA for the purpose of:
- Providing early access to the DexHand v2 schematics.
- Gathering technical feedback and insights to enhance the design.
- Exploring potential collaborative opportunities.

## Access & Confidentiality

This is a private repository and is currently accessible only to designated NVIDIA team members. While the repository is under an open-source license, we kindly request:
- No redistribution of files or designs outside NVIDIA without prior discussion.
- Any modifications or improvements be shared back.
